# Studio Import Implementation Plan

**Goal:** import Studio exports into reference operation configurations.
**Architecture:** validate/export provenance in Python, project resources in
Jsonnet, and reuse the existing catalog and runtime contracts.
**Tech stack:** Python standard library, Jsonnet, locked OE sources, GitHub CI.

## Constraints

Hub B/CIS1/oc1 and plain network platforms only; preserve network details and
project NSGs; reject unsupported choices; verify complete exported snapshots;
never run Terraform or OCI. User approved the integration design in chat.

- [ ] Add failing CLI/import tests using synthetic Studio literal configs and
  JSON generated by the real pinned OE entrypoint. Assert drift rejection,
  preserved subnet/NSG values, unsupported choices and archive traversal.
- [ ] Implement `scripts/studio.py` input validation, source/snapshot verification,
  model mapping, provenance and report. Add `import-studio` to the reference CLI.
- [ ] Extend `gen/project.libsonnet` to consume original Studio configs and retain
  their network fields/NSGs; validate multi-region IAM and runtime dependencies.
- [ ] Add model/Studio selection to the private workflow; document supported
  import commands, outputs, design adjustments and deployment boundaries.
- [ ] Run complete tests, generation, facade/docs/workflow checks; review the
  patch, publish a PR, verify remote CI and record the delivery in PKM.
